APP NAME
--------
Windows Resurface

DESCRIPTION
-----------
Utility focused on exposing commonly used but hidden Windows tools and locations.
UI should match Windows theme as closely as possible.


CORE HIDDEN WINDOWS LOCATIONS
-----------------------------
Event Viewer
System Information (msinfo32)
Disk Management
Network Reset / Network Diagnostics
Credential Manager
Local Users & Groups
Temp Files (%temp%)
Prefetch
Disk Cleanup (cleanmgr)
Startup Folder (shell:startup)
Common Startup Folder (shell:common startup)
Clipboard History
Windows Update Troubleshooter
Storage Sense / Cleanup Recommendations
Installed Programs (appwiz.cpl)
Advanced Display Settings
Windows Defender / Virus & Threat Protection
Hosts File
System Restore / Restore Points
Reliability Monitor (perfmon /rel)
Resource Monitor
Services (services.msc)
Windows Memory Diagnostic
AutoPlay Settings (control /name Microsoft.AutoPlay)
